## 1. 프로젝트 개요

이번 미션은 GenAI 미션들을 진행하며 쌓아온 프롬프트를 체계적으로 관리하기 위한
**콘솔 기반 프롬프트 관리 프로그램**을 파이썬으로 직접 구현하고, Git/GitHub로
버전 관리하는 것을 목표로 했다.

단순히 문법을 암기하는 데 그치지 않고, 리스트와 딕셔너리로 데이터를 다루는 논리,
함수 단위로 기능을 분리하는 구조적 사고, 그리고 Git으로 변경 이력을 관리하는
협업/버전관리 습관을 익히는 데 중점을 두었다.

## 3. 주요 기능 구현

프로그램은 메뉴 번호를 입력받아 각 기능을 실행하는 콘솔 프로그램으로,
총 6가지 핵심 기능과 종료 기능으로 구성했다.

### 3.1 기본 프롬프트 데이터

이전 GenAI 미션에서 실제로 작성했던 프롬프트 3개를 기본 데이터로 등록했다.
각 프롬프트는 `id`, `title`, `content`, `category`, `is_favorite` 5개 필드를
가진 딕셔너리로 구성하고, 이를 리스트(`prompts`)에 담아 관리한다.

| 제목 | 카테고리 | 즐겨찾기 |
|---|---|---|
| IT 기술 블로그 글 작성 페르소나 | 페르소나 | ⭐ |
| 사이버펑크 도시 배경 이미지 생성 | 이미지 생성 | - |
| 파이썬 코드 리팩토링 및 주석 추가 | 텍스트 생성 | - |

새 프롬프트를 추가할 때 ID가 겹치지 않도록 `get_next_id()` 헬퍼 함수를 만들어,
현재 등록된 프롬프트 중 가장 큰 ID에 1을 더해 새 ID를 발급하도록 구현했다.

### 3.2 프롬프트 목록 보기 (`show_prompt_list`)

전달받은 프롬프트 리스트를 순회하며 `ID`, 즐겨찾기 여부(⭐), 제목, 카테고리를
한 줄로 출력한다. 이 함수는 전체 목록 보기뿐 아니라 카테고리별 조회, 검색 결과,
즐겨찾기 목록 출력에도 재사용되도록 설계했다. 등록된 프롬프트가 없을 경우
안내 메시지를 출력한다.

### 3.3 프롬프트 추가 (`add_prompt`)

제목과 내용은 빈 값이 입력되면 `while` 반복문으로 재입력을 요구해 필수값을
보장했다. 카테고리는 별도로 입력받되, 비워두면 자동으로 "기타"로 지정되도록
기본값을 처리했다. 즐겨찾기 초기값은 `False`로 고정된다.

### 3.4 카테고리별 조회 (`show_by_category`)

고정된 카테고리 목록을 쓰는 대신, 현재 `prompts`에 실제로 존재하는 카테고리를
`set()`으로 중복 제거해 동적으로 보여주도록 구현했다. 사용자는 번호 또는
카테고리 이름을 직접 입력해 조회할 수 있으며, 해당 카테고리에 프롬프트가
없으면 안내 메시지를 출력한다.

### 3.5 키워드 검색 (`search_prompt`)

입력한 키워드를 제목과 내용 양쪽에서 대소문자 구분 없이(`lower()`) 검색한다.
검색 결과가 없을 경우 안내 메시지를 출력하고, 있을 경우 `show_prompt_list`를
재사용해 결과를 출력한다.

### 3.6 프롬프트 상세 보기 (`show_prompt_detail`)

ID를 입력받아 해당 프롬프트의 제목, 카테고리, 즐겨찾기 여부, 전체 내용을
출력한다. 숫자가 아닌 값이 입력되거나 존재하지 않는 ID일 경우 각각
안내 메시지를 출력해 예외 상황을 처리했다.

### 3.7 즐겨찾기 관리 (`manage_favorites`)

하나의 함수 안에서 서브 메뉴(①즐겨찾기만 모아보기 / ②즐겨찾기 추가·해제)를
제공하도록 구현했다. 추가·해제는 `is_favorite` 값을 `not` 연산으로 토글하는
방식으로 처리해, 같은 ID를 다시 입력하면 원래 상태로 되돌아가도록 했다.

## 4. 코드 구조

기능별로 함수를 분리해 하나의 함수가 하나의 책임만 갖도록 구성했다.

```
get_next_id()        # ID 자동 생성
show_menu()           # 메뉴 출력 및 입력 받기
show_prompt_list()    # 목록 출력 (여러 기능에서 재사용)
add_prompt()          # 프롬프트 추가
show_by_category()    # 카테고리별 조회
search_prompt()       # 키워드 검색
show_prompt_detail()  # 상세 보기
manage_favorites()    # 즐겨찾기 관리
main()                # 전체 메뉴 루프 제어
```

`main()`은 `while True` 루프 안에서 `show_menu()`의 반환값을 받아 각 함수를
분기 호출하고, `0`을 입력하면 루프를 종료하는 구조로 전체 흐름을 제어한다.

## 7. 배운 점 및 회고

- 리스트 안에 딕셔너리를 담아 여러 필드를 가진 데이터를 관리하는 방식과,
  이를 조건문·반복문으로 필터링/검색하는 로직을 직접 구현하며 익혔다.
- 기능을 함수 단위로 쪼개고, `show_prompt_list()`처럼 공통 로직을 재사용
  가능하게 설계하는 것이 코드 중복을 줄이는 데 도움이 된다는 것을 체감했다.
- Git으로 기능 단위 커밋을 남기고 브랜치를 나눠 작업하며 병합하는 흐름을
  실습하면서, 커밋 메시지로 변경 의도를 설명하는 습관의 중요성을 배웠다.
